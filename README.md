## Organización

- `index.html`: caso de estudio de las etapas de investigación, definición, ideación, prototipado y evaluación.
- `img/`: fotografías de ideación y del prototipo en papel, optimizadas para web.
- `anexos/`: informes originales, registro de cambios y prototipo navegable.

## Publicación en GitHub Pages

Subir el contenido de esta carpeta a la raíz del repositorio para que `index.html` quede en esa raíz. En GitHub, abrir **Settings → Pages** y seleccionar **Deploy from a branch**, rama `main`, carpeta `/ (root)`. El CDN de Tailwind requiere conexión a internet para compilar los estilos al abrir el sitio.

Antes de entregar, reemplazar “pendiente de publicar” por el enlace de GitHub Pages y abrirlo en otro dispositivo para confirmar que sea público.
